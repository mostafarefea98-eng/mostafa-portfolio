HOW I WORK

Understand it. Build it. Validate it.

01 — Understand the system

Start with the physical principle, requirements, interfaces, and constraints before jumping into implementation.

02 — Design a practical approach

Break the problem into blocks, select components carefully, and document assumptions and trade-offs.

03 — Test and improve

Measure real behavior, compare it with expected results, and use what the test teaches to improve the design.
