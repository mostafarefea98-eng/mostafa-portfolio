# Mostafa Engineering Portfolio

A responsive, single-file portfolio website with English/Arabic language switching.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.

## Publish for free
- **GitHub Pages:** Create a GitHub repository, upload `index.html`, then enable Pages in the repository settings.
- **Netlify:** Drag the folder (or a ZIP containing `index.html`) into Netlify's manual deploy area.
- **Vercel:** Import a repository containing the file.

No paid hosting is required for this static site. A custom domain is optional.

## Before making it public
- Replace the generic LinkedIn and GitHub links with your real profile URLs.
- Confirm the best contact method.
- Add real project photos, circuit/PCB renders, demo videos, source-code links, and verified results.
- Review all Notion links and remove any content that should remain private.
- The Power Distribution Board is labelled as a design study; the robotics car is labelled in development. Update statuses only when accurate.
